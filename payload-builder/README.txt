RUSH MARINE GAME-DATA ZIP HELPER v0.1.2

This helper is OPTIONAL. If you already have the compatible original game ZIP,
import it directly on your phone. No PC conversion is required.

For extracted game files:
1. Install Python 3 on your computer if it is not already installed.
2. Extract this helper ZIP into a folder.
3. Double-click RUN-GAME-DATA-ZIP-HELPER-WINDOWS.bat.
4. Select the folder containing 277700.mif and the 277700 folder.
5. Copy Rush_Marine_Data_for_Bridge_v0.1.2.zip to your phone.
6. Open Rush Marine Bridge, tap IMPORT RUSH MARINE ZIP and select it.

Command-line use on Windows/Linux/macOS:
python build_payload.py PATH_TO_GAME_FOLDER

The helper validates the exact English BREW 1.1.11 / CDM2030 128x160 inputs.
It copies the original files unchanged into a ZIP. No downloads, uploads,
Android SDK, Java conversion, or external Python packages are required.
The generated ZIP contains your game data. Keep it out of the public repository.
